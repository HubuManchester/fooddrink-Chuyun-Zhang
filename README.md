# Food-Drink — Final Assignment

.NET MAUI recipe app (**FoodDrinkApp**) for the Food and Drink coursework theme.

## Repository layout

| Path | Description |
|------|-------------|
| `FoodDrinkApp/` | Main MAUI application (MVVM) |
| `FoodDrinkApp.sln` | Visual Studio solution |
| `ProjectDevelopmentGuide.md` | Development and demo checklist |
| `MockApiConfiguration.md` | Optional API integration notes |
| `ProjectRequirements.pdf` | Course brief (reference) |

## Quick start

1. Open `FoodDrinkApp.sln` in Visual Studio 2022.
2. Select **Windows Machine** or an **Android emulator**.
3. Press **F5** to build and run.

See [FoodDrinkApp/README.md](FoodDrinkApp/README.md) for features, hardware demo notes, and the assessment checklist.
